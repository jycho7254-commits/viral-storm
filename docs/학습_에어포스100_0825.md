# 에어포스 바이럴 영상 100개 학습 리포트 (08-25)

## 데이터
- 유튜브 검색 102개 메타 (조회수 정렬) + 실제 영상 5개 다운로드/프레임 분석
- 검색어: air force 1 shorts / 나이키 에어포스 쇼츠 / outfit / styling tiktok

## 1. 콘텐츠 유형 분포 (102개)

| 유형 | 비중 | 예시 |
|---|---|---|
| **How-to (튜토리얼)** | 26% | 끈 묶는 법, 스타일링 법 — 1위 1100만 조회 |
| **Styling/Lookbook** | 25% | 코디 5~15가지 모음 |
| **Fit check (착용 인증)** | 22% | ON FEET, 착용샷 |
| **Outfit ideas** | 20% | 계절별/상황별 코디 |
| Custom/언박싱/리뷰 | 각 4~5% | 마커 커스텀 185만 조회 |

**핵심 발견: 우리 영상이 놓친 것 = "제품 자랑"이 아니라 "활용법"이 1등 콘텐츠**
- 1위(1100만): 끈 느슨하게 묶는 법 — 제품 설명 0, 해결책 100
- 3위(278만): "너가 에어포스 신는 방식 5가지 실수" — 반박형 훅

## 2. 프레임 분석으로 발견한 촬영 패턴

| 패턴 | 실측 사례 | 우리 적용 |
|---|---|---|
| **언박싱 하이앵글** | 흰 장갑 + 박스 클로즈업 (LV 언박싱) | 제품 등장 = 개봉 시점부터 |
| **1인칭 POV 착용** | 차 안/일상 공간에서 발 클로즈업 | "내가 신은 듯한" 몰입 — 실사 소스 필요 |
| **미니멀 스튜디오** | 순백 + 중심구도 + 부드러운 조명 | 이미 하고 있음 ✓ |

## 3. 훅(제목/첫문장) 패턴 상위 5

1. **How to** — 해결책 약속 ("느슨하게 묶는 법")
2. **숫자 리스트** — "5 실수" / "15 코디" / "6가지 방법"
3. **부정형 반박** — "신지 마라, 왜냐면 너가 잘못 신거든"
4. **계절/타이밍** — "여름 코디" "지금 최저가"
5. **질문형** — "이게 진짜 에어포스라고?"

| 장면 | 제품 클로즈업만 | **착용/일상 POV 포함** | 연예인/착용 컷 소스 필요 (형 지적 정확) |

## 5. 타 제품 일반화 — 상호 피드백

**게임 (트릭컬):**
- How-to형 = "초보 꿀팁 5가지" / "이거 모르면 손해"
- 숫자형 = "10연차 확률 실측" (형 QA 배경과 시너지)
- POV형 = "출퇴근 길 풀더빙" 실플레이

**의류/제품:**
- Fit check + 계절 타이밍 ("가을 코디")
- 반박형 = "이렇게 세탁하면 망해요"

**플랫폼/사이트:**
- How-to형 = "3분이면 되는 OO" 스크린 캡처
- 숫자형 = "사용자 87%가 모르는 기능"

**공통 결론: 제품을 '보여주는' 영상 → 제품으로 '문제를 푸는' 영상**
