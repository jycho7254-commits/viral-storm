## 4. 경쟁 게임 바이럴 마케팅 사례

### 원신 (HoYoverse)
- **전략:** 글로벌 캐릭터 마케팅 + 커뮤니티 자연스러운 확산
- **바이럴 포인트:** 캐릭터 일러스트 → 2차 창작 유도 → SNS 확산
- **우리가 배울 점:** 캐릭터 매력 어필 > 게임 시스템 어필
- **차별화:** "트릭컬은 3등신으로 정반대 간다"

### 붕괴: 스타레일
- **전략:** 밈 마케팅 + 유머러스한 공식 트위터
- **바이럴 포인트:** 공식 SNS가 밈을 만들면 커뮤니티가 확산
- **우리가 배울 점:** 공식+비공식 바이럴 혼합
- **차별화:** "한정캐 없음 = 과금 스트레스 제로"

### 승리의 여신: 니케
- **전략:** "그" 각도 마케팅 + 캐릭터 디자인 어필
- **바이럴 포인트:** 캐릭터 디자인 화제성 → 커뮤니티 확산
- **우리가 배울 점:** 시각적 화제성이 텍스트보다 강함
- **차별화:** "볼따구 귀여움으로 정반대"

### 트릭컬 리바이브 (에피드 게임즈)
- **전략:** 대표 마케팅 (집 담보 + 위험한 초대)
- **바이럴 포인트:** "미친 대표" 스토리텔링 → 화제성
- **우리가 배울 점:** 진정성 있는 스토리가 가장 강력한 바이럴
- **적용:** 개발진의 "올인" 스토리를 자연스럽게 녹이기

## 요약: Viral Storm 핵심 전략

1. **장르별 채널 최적화:** 서브컬처는 DC/아카, 캐주얼은 블로그
2. **페르소나 8종:** 기존 5종 + 주부/군인/복귀유저 추가
3. **시간대 분산:** 블로그 아침, DC 심야, X 점심
4. **경쟁 차별화:** "한정캐 없음 + 3등신 + 풀더빙"
5. **연령별 맞춤:** 10대=슬랜, 30대=일상, 40대=가족
