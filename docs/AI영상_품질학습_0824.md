# AI 바이럴 숏츠 품질 학습 시스템 (08-24)

## 형 피드백 반영
"지금 WAN 영상은 기괴하고 포인트를 못 잡는다. 내보낼 수 없는 수준"

## 레퍼런스 분석 결과 (형이 준 영상: IPvoi5sfXok, 22.9만 조회)

### 성공 AI 숏츠의 제작 공식
1. **컨셉 = "환상적 ASMR 제품 시연"**
   - 존재하지 않는 가상 제품 (과일 모양 키보드, 컵이 달린 키캡 등)
   - 손이 등장해 만지고 누르고 자름 → 촉감/ASMR 욕구 자극
   - 물리적으로 불가능한 것을 사실적으로 → AI여야만 가능한 콘텐츠 (AI 느낌이 콘셉트 자체)
2. **자막 구조**
   - 상단: 노란색 강조 + 흰색 조합, 큰 폰트 (훅: "이거 도대체 어떻게 AI로 만들었냐?")
   - 하단: 작은 흰색 자막
   - 문장이 매우 짧음 (10자 내외)
3. **영상 구조** (15초)
   - 0-3s: 훅 (기괴하지만 예쁜 것 등장)
   - 3-12s: ASMR 시연 3-4컷 (각 2-3초, 같은 컨셉 변형)
   - 12-15s: CTA (만드는 법 궁금하게)
4. **촬영 감각**
   - 정적 샷 + 미세한 움직임만 (빠른 줌 X)
   - 화면 비율 꽉 채움, 제품이 화면 2/3
   - 색감: 파스텔+비브라이트, 깨끗한 배경

### 우리 WAN 영상이 실패한 이유 (진단)
| 문제 | 원인 |
|---|---|
| 기괴함 | "캐릭터 파티클/전투" 같은 추상 프롬프트 → WAN 1.3B가 못 그리는 걸 시도 |
| 포인트 부재 | 제품이 화면에 뭉개져서 등장, 손/스케일 감각 없음 |
| 장면 연결 안 됨 | 클립마다 별개 컨셉 (일관된 세계관 X) |

## 새 프롬프트 전략 (AI숏츠 공식 적용)

### 게임 (트릭컬)
- "귀여운 3등신 캐릭터 인형이 매대에 진열되어 있음, 손가락이 하나를 집어 드는 클로즈업, 부드러운 스튜디오 조명" (제품 인형화 + 손)
- "작은 캐릭터들이 젤리 위를 뛰어다님, 파스텔 색감, 매크로 렌즈" (환상적+ASMR)
- ✗ 금지: "전투", "파티클", "마법" → 1.3B가 뭉갬

### 제품 (의류/신발)
- "발이 신발 안에 들어가는 슬로모션, 깨끗한 배경" (손/발 = 인간 감각)
- "옷이 바람에 흩날리는 클로즈업, 순백 스튜디오"
- ✗ 금지: 전신샷, 마네킹 회전 (현재 방식 = 뭉개짐)

### 공통 룰
1. 한 클립 = 하나의 동작만 (2초)
2. "손" 또는 신체 일부 반드시 포함 → AI여도 리얼함↑
3. 색감 키워드 필수: "pastel colors, clean studio lighting, soft focus"
4. 클로즈업/매크로 위주 (전체 장면 X — 작은 모델일수록 클로즈업이 잘 됨)
5. 4클립 = 같은 제품의 다른 각도/동작 (일관성)
