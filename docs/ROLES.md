# Viral Storm — 역할 분담

## 프로필별 역할

| 프로필 | 역할 | 담당 영역 | Hermes 프로필 |
|--------|------|----------|--------------|
| **2호** | 개발 총괄 | AI 글 생성 엔진, FastAPI 백엔드, 웹 대시보드, 플랫폼 자동화, 배포 | `default` |
| **3호** | BM/전략 분석 | 타겟 고객 분석, 경쟁작 리서치, 마케팅 전략 수립, 페르소나 튜닝 | `zh3` |
| **OMP** | 품질 검증 | 글 품질 검증, AI 냄새 체크, 링크 정확도, 발행 전 최종 확인 | 위임 (서브에이전트) |
| **명훈** | 최종 승인 | 캠페인 승인, 방향 결정, 계정 관리 | — |

## 협업 워크플로우

```
[명훈] 캠페인 생성 요청
    │
    ▼
[2호] 캠페인 등록 + AI 글 생성
    │
    ├──▶ [3호] 타겟 분석 + 경쟁작 리서치 + 페르소나 피드백
    │         │
    │         ▼
    │    [2호] 3호 피드백 반영하여 글 재생성
    │
    ▼
[OMP] 품질 검증 (AI 냄새, 키워드 밀도, 링크)
    │
    ├── PASS → 발행 큐
    └── FAIL → [2호] 재생성
    │
    ▼
[명훈] 최종 승인 → 발행
```

## 작업 할당 규칙

- 2호가 Kanban 보드에 작업 생성 → 3호/OMP에 할당
- 3호는 BM/전략 분석 결과를 TODO.md에 기록
- OMP는 서브에이전트로 실행, 결과를 TODO.md에 PASS/FAIL 기록
- 2호는 매 작업 완료 시 TODO.md와 README 갱신
