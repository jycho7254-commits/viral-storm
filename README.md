## 주요 기능

| 모듈 | 내용 |
|---|---|
| **영상 엔진** | WAN 2.1 로컬(검증프롬프트 뱅크) + 실사 하이브리드, 1080x1920 |
| **사운드** | 비트싱크 컷(librosa), 에너지 더킹, 사이드체인, 크로스페이드 |
| **폰트 팔레트** | BlackHanSans(훅) / NotoSansKR(본론) / Jua(CTA) |
| **자막** | ASS 기반 — 볼드+외곽선+노랑강조, 호흡 단위 줄바꿈, 팝 애니메이션 |
| **글 생성** | 플랫폼별 패턴 (YT=질문형 / 블로그=찐후기 / DC=정보모음 / X=숏펀치) |
| **발행** | APScheduler 시간대 분산 (블로그 10/20시, DC 12:30/18:30/23시, X 9/13/17/21시) |
| **웹 대시보드** | localhost:8100 — KPI 12종, Chart.js 성과차트 |
